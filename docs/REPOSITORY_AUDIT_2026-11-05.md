## 本 PR 的范围

新增 `experiments/` 作为统一实验入口，旧 `code/`、`gpu/`、`results/` 原样保留。
只提供资产登记与标准化配对评估；不臆造训练入口，不重训已完成实验，不安装依赖、不下载模型。
目录登记不认证模型内容；小文件哈希仅证明这次所读文件的内容，不认证训练实际发生。
尚不能确定服务器模型目录、三种子的具体数值、TRL/PEFT 版本、数据划分、超参数或日志格式。

合并前后都应保留 GitHub 与服务器的独立身份：训练代码版本未知则记 unknown；不要用本 PR 的 SHA 追认旧训练。
